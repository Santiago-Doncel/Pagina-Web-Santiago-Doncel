## 🌐 Publicación en GitHub Pages

1. Crea un repositorio público en [GitHub](https://github.com/Santiago-Doncel) llamado `portafolio-santiago-doncel`.
2. En tu terminal o consola:
   ```powershell
   cd C:\Users\santd\.gemini\antigravity\scratch\portafolio-santiago-doncel
   git add -A
   git commit -m "Refactor: diseno minimalista liquid glass, tipografia Bodoni y galeria de marketing"
   git remote add origin https://github.com/Santiago-Doncel/portafolio-santiago-doncel.git
   git branch -M main
   git push -u origin main
   ```
3. En GitHub, abre **Settings > Pages**, en **Source** selecciona **"Deploy from a branch"**, rama `main` y carpeta `/ (root)`.
4. El sitio estará disponible globalmente en:  
   👉 **`https://santiago-doncel.github.io/portafolio-santiago-doncel/`**
